# Agent context

Read [ops/WORKFLOW.md](ops/WORKFLOW.md) before work. The Supervisor owns [ops/TASK.md](ops/TASK.md) and [ops/REVIEW.md](ops/REVIEW.md); the Programmer owns [ops/IMPLEMENTATION_REPORT.md](ops/IMPLEMENTATION_REPORT.md); the Overseer records decisions in [ops/DECISIONS.md](ops/DECISIONS.md). Follow the active task's path and test boundaries.

When a task needs architecture context, query the existing Graphify graph and read `graphify-out/GRAPH_REPORT.md`. Update Graphify when the graph is stale, within the task's allowed paths or after the Supervisor expands those paths. Cite source files when making implementation or review claims.
